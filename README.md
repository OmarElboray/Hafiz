An advanced, client-side web platform engineered for real-time Quranic voice verification (`Tasmi3`) and active recall tracking. Hafiz utilizes native browser audio streams and string-alignment algorithms to evaluate pronunciation and memorization accuracy on-the-fly.

---

## ⚡ Core Technical Blueprint

Unlike traditional applications that rely on heavy, expensive cloud APIs for audio transcribing, Hafiz executes its entire parsing pipeline **directly on the user's device**.
